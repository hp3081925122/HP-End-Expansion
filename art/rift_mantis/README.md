# 裂隙螳螂

本次交付为静态生物模型、关节骨骼、原生像素贴图与 UV。参考图由内置 imagegen 生成，几何通过本地 Blockbench MCP 创建并检查。

根据用户对胸颈过长的反馈，头部与触角整体下移 5 个模型单位、前移 1 个单位；胸颈的垂直跨度由 15 缩至 10 个单位。原始参考图保留，最终比例以可编辑模型为准。

镰刃已改成实体刃背配合透明裁切面片（Alpha Cutout）：两侧各一片，用原生像素轮廓绘出弯曲内刃和收尖末端，刃背保留厚度。分件、整模及导出使用同一版造型。

## 文件

- `rift_mantis.bbmodel`：整模，可直接在 Blockbench 中打开，内嵌最终贴图。
- `export/rift_mantis.geo.json`：GeckoLib 几何导出，标识为 `geometry.rift_mantis`。
- `export/rift_mantis.png`：原生 128×128 RGBA 基础贴图。
- `export/rift_mantis_uv.png`：同尺寸 UV 岛轮廓。
- `export/uv_layout.json`：体块、部位与各面的 UV 对应表。
- `parts/`：头部、躯干、镰臂、步足四份独立可编辑工程，各有 PNG 贴图和 UV 图。
- `reference/`：原始参考三视图、生成提示词及确定的材质色板。
- `model_preview.png`、`uv_preview.png`：实际模型及 UV 展示板。
- `qa/turntable.webp`：对最终导出几何重新导入后录制的连续环绕与俯仰记录。
- `qa/reference_comparison.png`：参考局部与实际分件模型的对照。

## 规格

- 42 个实体体块、2 个透明面片，25 个骨骼，1 张 128×128 贴图。
- 16 个模型单位等于 1 格；四足支撑，双侧镰臂。
- 根骨骼 `root` 下为 `body`；胸颈 `neck` 承接头部与双臂，腹部及步足由 `body` 承接。
- 头部、双触角、腹部、双臂关节和各足关节可独立制作动画。
- 对称部件使用按几何反射换算的 UV；图集直接在原生像素网格绘制，未从参考图缩小或像素化生成。
- `UV` 图颜色：青色为躯干，黄色为头部，紫色为镰臂，绿色为步足。

## 已完成检查

- 主工程与四个部件文件的 UUID、名称、骨骼引用与层级核对通过。
- 主工程与 geo 导出均为 44 个几何元素、25 个骨骼，骨骼名称及父子关系一致。
- 256 个有效面的 UV 全部在图集边界内；两个面片各保留正反两面，UV 内包含透明裁切区域。
- 图集 alpha 仅含 0 和 255；8408 个不透明像素、7976 个透明像素。
- 主工程嵌入贴图与导出 PNG 的 RGBA 像素完全一致。
- GeckoLib 插件校验为 0 错误、0 警告。
- 将最终 geo 重新导入 Blockbench 后，检查了 72 帧连续环绕和 21 帧俯仰视角；所查视角未见明显缺面或表面闪烁。静态站姿的连接、四足间距与左右镜像已检查。

本次未制作行走、攻击或瞬移动画，也未接入游戏实体。紫色刃缘和眼部目前属于基础贴图色彩，游戏端自发光与动态特效尚未接入、验证。
