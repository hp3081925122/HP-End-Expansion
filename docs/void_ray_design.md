# 裂空鳐 设计文档

末地精英怪，飞行型。盘旋在外岛上空的巨型鳐鱼，腹部有一枚虚空核心。它与地面近战的裂隙螳螂互补，负责空中压制和地形威胁。

状态：模型、动画、AI、技能、特效、掉落与生成已实现，待游戏内测试。

## 1. 定位

| 项目 | 内容 |
|---|---|
| 类型 | 精英怪，单体遭遇 |
| 目标玩家 | 击败末影龙之后，下界合金装备前后 |
| 战斗风格 | 空中游击：高空盘旋放远程技能，定时俯冲贴近，给玩家留出反击窗口 |
| 与裂隙螳螂的区别 | 螳螂靠闪现贴身、逼玩家横移；裂空鳐靠飞行和射线、逼玩家抬头找掩体和出手时机 |
| 预期击杀时间 | 下界合金剑配弓，约 30～45 秒 |

## 2. 基础属性

| 属性 | 数值 | 说明 |
|---|---|---|
| 生命 | 130 | 比螳螂低，飞行难命中作为补偿 |
| 攻击 | 10 | 俯冲撞击的基础值 |
| 护甲 | 6 | |
| 飞行速度 | 0.5 | 巡航；俯冲时由技能直接设置速度 |
| 击退抗性 | 0.6 | |
| 追踪距离 | 48 | |
| 经验 | 40 | |
| 碰撞箱 | 3.0 × 1.2 | 扁平，翼展大，便于被箭命中 |

- 飞行：无重力，使用飞行移动与飞行寻路，巡航高度保持在目标上方 6～10 格。
- 索敌：受击反击，主动攻击 32 格内的玩家。
- 弱点：腹部虚空核心，受到来自下方的弹射物伤害 × 1.5。

## 3. 技能

同一时刻只释放一个技能，施法期间持续朝向目标。空闲时盘旋，并按以下规则挑选技能：

| 技能 | 触发条件 | 冷却 | 阶段 |
|---|---|---|---|
| 俯冲穿刺 | 水平距离 6～20，有视线 | 6 秒 | 全程 |
| 虚空射线 | 距离 8～28，有视线 | 9 秒 | 全程 |
| 引力漩涡 | 目标在地面，距离小于 24 | 12 秒 | 全程 |
| 星陨 | 第二阶段，距离小于 24 | 20 秒 | 第二阶段 |

### 3.1 俯冲穿刺
- 前摇 0.8 秒：身体后仰、双翼收拢。地面出现一条从目标脚下向前延伸的紫色预警线，长 10 格。
- 俯冲 0.6 秒：沿预警线方向高速冲下再拉起，路径在前摇结束时锁定。
- 判定：沿路径半径 1.5 格，15 伤害，向上击飞 0.6，不做水平击退，避免把玩家推下虚空。
- 收招 0.8 秒：低空滑行、拉升，是近战反击窗口。
- 特效：
  - 预警线：地面贴花条带，前摇期间由暗变亮。
  - 俯冲：尾部拖出 Ribbon 拖尾，记录最近约 10 个位置点。
  - 命中：碎片粒子外加一圈地面冲击环。

### 3.2 虚空射线
- 前摇 1.0 秒：腹部核心逐渐发亮，核心周围向内吸入火花。
- 引导 2.0 秒：从核心射出射线，每 tick 最多转向 4°，玩家横移就能甩开。
- 判定：射线命中的第一个实体，每 0.5 秒 5 伤害；举盾格挡时伤害减半。射线会被方块阻挡，掩体有效。
- 收招 0.6 秒：核心过热冒烟，这时受到的伤害 × 1.3。
- 特效：
  - 射线：三层同心圆柱（外晕、过渡层、白芯），外层按时间脉动。
  - 落点：灼烧光斑加少量火花。
  - 被方块阻挡时，在阻挡面生成光斑。

### 3.3 引力漩涡
- 前摇 1.2 秒：在目标脚下的实心地面上生成直径 7 格的旋转符文圈。
- 生效 2.5 秒：圈内实体每 tick 被拉向圆心，拉力 0.08；圆心每 0.5 秒 3 伤害。
- 安全规则：只能在实心方块上生成，圆心周围 3 格内必须没有虚空；找不到合适位置就不释放。
- 结束：圈内实体受到 0.6 的向上冲击，之后接一次俯冲的概率提高。
- 特效：
  - 地面：两层反向旋转的符文环，外层用加法混合。
  - 圆心：竖直的吸入光柱。
  - 碎石：少量碎片粒子螺旋向内。

### 3.4 星陨（第二阶段）
- 触发：生命首次低于 50% 进入第二阶段，立即可用；之后每 20 秒一次。
- 过程：悬停蓄力 0.9 秒，背部裂开，向目标周围抛出 5 颗陨星（第二阶段为 7 颗，其中一颗对准目标脚下）。
- 落点：每颗先在地面出现收紧的预警环，1.2 秒后落地，相邻两颗间隔 0.2 秒；落点下方没有地面时跳过。
- 判定：落点半径 2 格，8 魔法伤害，向上弹起 0.45。
- 第二阶段：所有技能冷却 × 0.75，巡航高度降低 2 格。
- 特效：背部裂缝火花、预警环收紧、晶核带拖尾坠落、落地冲击环与碎片。
- 动画：复用 `brood_burst`。

## 4. 反制与公平性

- 所有技能都有地面预警或核心发光作为前摇提示，前摇都不短于 0.8 秒。
- 击飞只朝上，不做水平击退，也不在虚空边缘生成漩涡。
- 俯冲收招和射线收招是主要的输出窗口；弓和弩可以随时打核心弱点。
- 玩家离开 48 格或死亡后，它回到巡航高度并恢复生命。

## 5. 模型与动画

### 骨骼（GeckoLib）
```
root
└── body
    ├── head
    │   ├── eye_left / eye_right
    │   └── horn_left / horn_right
    ├── core                          自发光核心，射线起点
    ├── back_crack                    第二阶段背部裂缝
    ├── wing_left_1 → wing_left_2 → wing_left_3
    ├── wing_right_1 → wing_right_2 → wing_right_3
    └── tail_1 → tail_2 → tail_3 → tail_4 → tail_stinger
```
- 翼：每侧 3 段，靠近身体的一段用实体块，外缘用透明面片画出翼膜轮廓。
- 尾：5 段，用来做波浪摆动。
- 贴图：128 × 128，外加 glowmask，发光范围是核心、眼睛和翼缘裂纹。
- 配色：沿用本模组的末地紫色系，与裂隙螳螂一致；核心用高光色 #E8C9FF。

### 动画
| 名称 | 类型 | 用途 |
|---|---|---|
| idle_fly | 循环 | 慢速拍翼，尾巴波浪摆动 |
| glide | 循环 | 巡航，翼展平，只做小幅摆动 |
| dive_start / dive_loop / dive_end | 单次 / 循环 / 单次 | 俯冲三段 |
| beam_start / beam_loop / beam_end | 单次 / 循环 / 单次 | 射线三段 |
| vortex_cast | 单次 | 双翼上举，向下压 |
| brood_burst | 单次 | 悬停，背部裂开（星陨） |
| hurt | 单次 | 受击抖动 |
| death | 保持 | 失去升力，翻滚坠落 |

## 6. 生成

- 群系：`end_highlands`、`end_midlands`、`end_barrens`，不在主岛生成。
- 权重 2，每组 1 只。玩家周围 64 格内最多 1 只。

| 物品 | 数量 | 概率 | 用途 |

## 9. 风险

- 飞行寻路在末地外岛的紫颂丛和浮空结构附近可能卡住，需要实测，并准备脱困逻辑。
- 射线每 tick 做射线检测和渲染，多只同屏时要控制圆柱的分段数和层数。
- 生成上限只靠权重 2 控制，没有做 64 格内唯一的限制，需实测密度。
