# Minecraft 1.20.1 Forge 迁移

基于主分支 `0558918` 的 HP End Expansion 2.0，独立分支为 `1201forge`。较早的 Forge 版本保存在 `archive/1201forge-before-2.0`，主分支和其他版本工作树不受本次迁移影响。

## 开发环境

- Minecraft 1.20.1，Forge 47.4.23，Java 17。
- GeckoLib Forge 4.8.4，Curios Forge 5.14.1+1.20.1。
- JEI、Jade 仅用于开发运行环境。
- TerraBlender 保留可选兼容，不列为强制依赖。

在本工作树使用 Java 17 执行 `./gradlew.bat build`。正式产物是 `build/libs/hp_end_expansion-1.20.1-forge-2.0.jar`，已执行 Forge 重混淆；Java 字节码版本为 17。

## 保留与适配

39 个实体 ID 与原分支完全一致，全部拥有对应客户端渲染注册。原有模型、动画和贴图内容保留，包括碎潮拳虾的正式实体及攻击动画。

AI 目标选择和受击反击逻辑与原分支一致，包括负星者、召星者、逐星兽和殉星者原有的主动寻找玩家行为。

潮光之弩的弹仓使用 ItemStack NBT 保存，保留箭矢类型、多轮储备、左键发射、长按右键连续装填、快速装填和多重射击。主副手共享弩的 +3 装填容量；遗物容量、自动选弩规则、虚空核心去重和锤芯的发射时及命中时增伤上限均保留。群星之弓的多段蓄力、追踪与胸甲反弹也已适配。

天空、技能特效、屏幕效果、群系音乐及首领音乐使用 Forge 1.20.1 对应的渲染和事件接口。原版 1.21 重锤砸地音效作为模组音效保留。

配方、战利品、配方解锁、标签、群系修饰器和结构目录已转换为 1.20.1 的格式。5 个结构的方块与结构标记兼容旧版，版本标记调整为 3465。余烬的 1200 刻燃料时间改用 Forge 物品接口提供。

鲸落附魔书仍按附魔标签选择候选项，支持修改标签。横扫附魔 ID 转为 `minecraft:sweeping`；1.20.1 原版不存在的 `breach`、`density` 引用为可选项，当前可用候选池为 35 项。殉星者的附魔掉率保留为无抢夺 10%、抢夺 I 12%，之后每级增加 3%，避免旧版公式改变概率。

## 验证

已通过 `clean build`、资源 JSON 校验、注册 ID 对比和正式 JAR 检查。JAR 包含正确的 Forge 元数据、资源包格式 15、Mixin 配置和重映射文件，不含临时测试类或测试结构。

扩展服务器 GameTest 全部通过，共 44 项。其中弩及资源适配的 6 项基础测试如下：

1. 全部 39 个实体可创建，关键配方和 5 个结构可加载。
2. 长按右键连续装满 3 轮，装填满时停止；NBT 往返保存后轮数及光灵箭类型不丢失，射击仅消耗一轮。
3. 主副手弩和多个虚空核心不叠加；移除一件时剩余加成保持，全部移除时撤销加成。
4. 潮冠触腕持续选择已装填最多的弩，该弩装满后不会转去装其他弩。
5. 原版多重射击与蟹钳加成共同生效；锤芯按装填轮数增伤，并在命中时按当前容量限制增伤。
6. 鲸落附魔候选池及等级范围有效，殉星者掉率曲线及两个群系注册正确。

验证脚本、临时测试源码、测试世界和日志保存在 `D:/AI临时文件/hp-end-expansion-1201forge`。

完整服务端测试覆盖和修复记录见 [服务端验证记录](1.20.1-forge服务端验证.md)。扩展测试还覆盖 12 种战斗生物的原生 AI、85 个技能状态、21 种生物的运行及 NBT、38 个配方、59 张战利品表、酿造、遗物命中与读档、召唤、配置热重载，以及群系、特征和结构放置。

未启动客户端，因此贴图显示、天空和技能特效的实际画面仍需游戏内检查。建议检查碎潮拳虾攻击动画、两个群系天空及音乐、首领屏幕效果、群星之弓和潮光之弩的操作与遗物组合。
