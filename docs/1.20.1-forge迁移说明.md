# Minecraft 1.20.1 Forge 迁移

基于主分支 `0558918` 的 HP End Expansion 2.0，独立分支为 `1201forge`。较早的 Forge 分支已按用户要求删除，其完整历史备份保存在 `D:/AI临时文件/hp-end-expansion-1201forge/branch-backups`，主分支和其他版本工作树保留。

## 开发环境

- Minecraft 1.20.1，Forge 47.4.23，Java 17。
- GeckoLib Forge 4.8.4，Curios Forge 5.14.1+1.20.1。
- JEI、Jade 仅用于开发运行环境。
- TerraBlender 保留可选兼容，不列为强制依赖。

在本工作树使用 Java 17 执行 `./gradlew.bat build`。正式产物是 `build/libs/hp_end_expansion-1.20.1-forge-2.0.jar`，已执行 Forge 重混淆；Java 字节码版本为 17。

## 保留与适配

39 个实体 ID 与原分支完全一致，全部拥有对应客户端渲染注册。原有模型、动画和贴图内容保留，包括碎潮拳虾的正式实体及攻击动画。

AI 目标选择和受击反击逻辑与原分支一致，包括负星者、召星者、逐星兽和殉星者原有的主动寻找玩家行为。

潮光之弩的弹仓使用 ItemStack NBT 保存，保留箭矢类型、多轮储备、左键发射、长按右键连续装填、快速装填和多重射击。主副手共享弩的 +3 装填容量；遗物容量、自动选弩规则、虚空核心去重和锤芯的发射时及命中时增伤上限均保留。群星之弓的多段蓄力、追踪与胸甲反弹也已适配。

天空、技能特效、屏幕效果、群系音乐及首领音乐使用 Forge 1.20.1 对应的渲染和事件接口。原版 1.21 重锤砸地音效作为模组音效保留。

配方、战利品、配方解锁、标签、群系修饰器和结构目录已转换为 1.20.1 的格式。5 个结构的方块与结构标记兼容旧版，版本标记调整为 3465。余烬的 1200 刻燃料时间改用 Forge 物品接口提供。

鲸落附魔书仍按附魔标签选择候选项，支持修改标签。横扫附魔 ID 转为 `minecraft:sweeping`；1.20.1 原版不存在的 `breach`、`density` 引用为可选项，当前可用候选池为 35 项。殉星者的附魔掉率保留为无抢夺 10%、抢夺 I 12%，之后每级增加 3%，避免旧版公式改变概率。

## 逐星兽踏地渲染对齐

2026-10-13 对照 1.21.1 后，确认逐星兽地裂的 7 条折线、每条 4 段、半径/宽度/颜色算法、贴图、模型与动画一致，GeckoLib 两版也都在恢复模型变换后调用特效绘制。视觉差异不能通过修改裂缝几何参数来解释。

当前 Minecraft 1.20.1 的 `rendertype_eyes.json` 声明普通透明混合，`ShaderInstance.apply` 会重新应用它；1.21.1 已移除此着色器混合配置及应用步骤，由 `RenderType.eyes` 保持 `ONE + ONE` 加法混合。Forge 对齐方案是为本模组的星骸发光特效注册独立的着色器描述，复用 1.20.1 原版发光顶点/片段程序并显式使用加法混合，保留原几何、纹理、雾和深度行为，不覆盖原版实体的着色器。

方案已实现，`clean build` 与正式 JAR 检查通过。另在无窗口 JVM 中调用实际 `ShaderInstance.parseBlendNode`，验证原版配置解析为 `SRC_ALPHA / ONE_MINUS_SRC_ALPHA`，修复配置解析为 `ONE / ONE`，RGB/Alpha 混合因子与加法运算均与 1.21.1 一致，其他描述字段与原版 1.20.1 完全相同。这个检查没有创建 OpenGL 上下文，不能证明实际画面已对齐。

构建日志：`D:/AI临时文件/hp-end-expansion-1201forge/star-chaser-vfx-build.log`；参数验证日志：同目录 `starfall-shader-validation-3.log`。当前正式 JAR 大小 5,611,584 字节，SHA-256：`22d6b84f718d9c7ed43da9edbdbb7576ea81f02dbaa6e754c3f28a8c21b4f461`，不包含临时验证类。

下次启动客户端后，对比逐星兽地裂的金白核心、橙色软边及亮光叠加，检查其他星骸光柱、拖尾和光晕；使用不同实体/动作时裂缝会按原有随机种子生成不同长度和折线。资源重载时应再次出现英文日志 `Starfall additive shader loaded with ONE + ONE blending`。
