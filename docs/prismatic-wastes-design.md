# 折光荒原 · 末地生物群系设计

版本：2026-09-06。原创陆地方案；创意不取材于另外两个任务或既有群系。实现环境：Minecraft 1.21.1、NeoForge 21.1.233、Java 21、GeckoLib 4.9.2。对应[总任务表](prismatic-task-plan.md)与[分批任务表](prismatic-parallel-tasks.md)。

## 1. 玩家印象与空间

远看是黑紫色末地岛上的一片暖白色裂地：琥珀色矮草沿岩层裂缝生长，烟蓝色矿木伸出扁平镜叶，淡紫棱柱把昏暗天空切成细小亮点。近处能看到生物背甲中缓慢积累的光，废弃建筑则用深色陶石遮住刺眼的矿脉。没有海、水池、潮汐、水生动物或海底建筑。

地貌保留末地岛屿轮廓，在外岛高地与中地形成连片斑块，地表覆盖燧白壳岩与风化棱土。低矮断层、稀疏矿木和局部晶柱制造遮挡，地表整体仍可徒步。植被稠密的“集光带”、裸露的“裂镜地”和围绕遗迹的“暗荫区”是同一群系中的景观组合，不增加三个独立注册群系。核心岛和虚空小岛不被替换。

配色：燧白 #D8CEB0，烟蓝 #607D91，深紫 #302739，储光琥珀 #EDAC50，危险洋红 #D56CB0。普通资源以暖光表示；攻击前摇使用洋红与实体姿态共同提示，避免只靠颜色辨认。环境声音使用稀疏结晶轻响和干燥沙砾脚步，不持续高频响铃。

## 2. 生态规则与资源循环

“光”是虚空环境能量的世界观解释，不检查末地不存在的正常昼夜日照，也不引入全区动态光照模拟。集光草、灯盏花和矿木把矿质固定为植物组织；棱兔食用晶芽，片角羊啃食硬茎；碎晶虫回收掉落晶屑，暮翅蛾在花间活动。敌对生物夺取储光器官，精英守护能量浓度最高的旧设施。

实现闭环：棱土上种植 → 植物随机刻成熟 → 右键采收保留植株 → 晶芽饲喂/繁殖生态生物 → 获得可再生晶屑、柔丝或矿角 → 建材、食物和探索工具。碎晶虫喂食晶屑后产生棱壤粉；棱壤粉催熟植物，避免只靠不可再生矿脉。生物产物有存档冷却，不可连续右键刷取。成熟植株用不同形状与亮度反馈状态。

生态只在已加载区域运行。植物沿用随机刻；生物目标搜索限制半径、间隔和候选数量。自然动物不主动大范围摧毁地形，避免长期把群系吃空。自动化产量由冷却控制，不靠无限掉落实体堆积。

## 3. 四种生态生物

| 生物 / ID | 外形与生态 | 玩家交互 | 基础数值目标 |
|---|---|---|---|
| 碎晶虫 `shardling` | 六足扁背、小型拼片甲壳，地面回收者 | 喂晶屑，冷却后产棱壤粉；受击逃跑 | 10 生命，速度 0.18 |
| 棱兔 `prism_hare` | 长后腿、双棱耳、短尾，吃晶芽 | 晶芽引诱和繁殖，低概率生物掉落不作为必需材料 | 12 生命，速度 0.30 |

## 5. 两种精英

### 裂层卫 `fault_warden`

大型低重心六肢甲兽，背部晶脊一侧断裂，磨晶工坊的驻守者。140 生命、10 基础伤害。轮换“正面重击”和“裂层冲锋”：抬前肢蓄力，锁定方向后冲出，命中受地形碰撞约束；冲锋结束暴露腹部并停顿。玩家可绕柱、横移、攻击收招期。首次驻守实例由结构放置一次，不能随区块重载重复复制。掉落裂层印 `fault_sigil` 和甲片。

### 狩镜者 `mirror_huntress`

高脚双镰、背负斜镜框的掠食者，断镜观测所精英。120 生命、8 基础伤害。轮换“三道扇形晶针”和“锁线突进”：先抬镰划定方向，再释放固定角度攻击，最后收镰。用观察姿态和掩体破解，不靠猜真假无敌分身。掉落镜面印 `mirror_sigil` 和暮丝。

两种精英的外形、位移和安全窗口不同；均可独立挑战，无须先打 Boss。数值为首版平衡目标，完成真实战斗验证后可调整并在此记录。

## 6. 首领：万相冕主 `parallax_regent`

一只四足矿质巨兽托起开放冠环，前躯宽、后躯窄，冠环中悬有可见核心。480 生命，基础伤害 10，Boss 血条。栖居无顶、宽阔、四角有遮挡柱的“万相庭”。玩家用裂层印、镜面印、蓄光晶和暮丝合成双印棱钥，在祭台右键召唤。召唤前检查范围内没有存活的同类 Boss，确认实体加入成功才消耗钥匙；仪式进度与结构状态可保存。

| 阶段 | 技能组合 | 可观察提示与应对 |
|---|---|---|
| 100%—60% | 前足横扫、锁线棱光 | 抬肢/冠环前倾 1 秒左右；离开正前方，锁线后横移 |
| 60%—25% | 加入扩散环击、双次锁线 | 冠环张开并停步，环形地面提示；远离近身圈，利用四柱 |
| 25%—0% | 缩短技能间隔，三次交替定线 | 保留每次前摇和收招；没有全场必伤，无限召唤或永久追踪 |

阶段转换只触发一次，保存阶段和巢点；战斗伤害不穿过完整掩体，不破坏玩家建筑，不强制改变玩家视角或无限刷怪。离开巢区或长期失去目标时返巢，防止拖出后乱跑；不因短暂丢目标无条件回满血。Boss 掉万相核心 `regent_core`，用于合成折光护符和高亮建筑灯，不提供无代价飞行或取代鞘翅。

战斗视觉需使用模型动作、稳定的地面/光束载体与有限粒子配合。仅有粒子时标注为原型，不能作为最终完成证据。

## 8. 四类探索结构与进程

| 结构 | 内容与空间 | 收获/教学 | 定位 |
|---|---|---|---|
| 折光路站 `prismatic_waystation` | 小型开放雨棚、定线标、种植槽和箱子 | 基础补给、种子，提示成熟采收与喂食 | 常见，探索入口 |
| 废弃磨晶工坊 `prismatic_polishing_works` | 宽阔车间、矮墙、料堆和侧门 | 裂层卫、裂层印、储光材料；用柱子规避冲锋 | 中等稀有 |
| 断镜观测所 `prismatic_broken_observatory` | 破损镜架、高低平台与完整掩体 | 狩镜者、镜面印、暮丝；练习锁线攻击应对 | 中等稀有 |
| 万相庭 `prismatic_prism_court` | 约 33×33 室外庭院、四柱、中心祭台、两侧进入通道 | 双印棱钥召唤首领；胜利取得核心 | 稀有终点 |

四种结构均为可 `/locate structure` 的真实结构注册项，自然生成限于本群系；不能把散落 Feature 伪称完整可定位结构。结构需要地基并尊重高度，不在虚空悬空生成大平板。实体/箱子只随结构生成一次，战利品箱使用数据表，不能每次进区块重新填充。

进程：发现路站 → 移植植被建立补给 → 探索两个精英设施获得双印 → 合成棱钥 → 定位万相庭 → 挑战 Boss → 核心护符和灯饰。战利品兼顾一次探索奖励与可再生材料。提供游戏内说明（物品提示/手册）和开发验收指令，不要求玩家阅读 Java 源码才能理解机制。

## 9. 实现边界、事实与验证

已确认：项目依赖版本、Gradle 8.8 + Java 21、GeckoLib 实体惯例、原版 `TheEndBiomeSource` 的构造参数/可能群系列表/采样入口，来源为本地当前版本源码。Minecraft MCP 索引工具未在当前工具列表中暴露，使用已定位的同版本源码和依赖进行核验。

2026-09-06 实现验证：独立功能已完成，19 项服务端测试、正式构建和资源审查通过，包括动态注册表、四设施原版定位及自然生成、合法祭台召唤、采样性能与关键生态/战斗存档。UV 和 66 个动作已离线审查。证据见 [验证记录](prismatic-verification.md)。

待验证：实际客户端资源渲染与手感、合并后的多个末地 Mixin 组合，以及最终通过 Blockbench MCP 检查另外两个任务的所有模型。不能把本功能通过编译或离线审查当作这些项目通过。

风险：新增多个群系独立修改同一末地采样方法会互相覆盖；最终集成统一路由，保证所有群系进入 possibleBiomes 且共享规则有明确优先级。大结构、扫描与粒子可能拖慢生成/战斗；采样只使用确定性计算，结构按区块裁切写入，不预加载远区块，粒子只发附近玩家。大量模型的 UV 与骨骼须逐项检查。已有地形不会自动重生成。

所有工作在 `feature/prismatic-wastes` 独立目录进行；只在两个外部任务结束后进行最终合并。合并前各分支推送备份，最终集成验证后再次推送；记录哈希和未完成项。不能覆写正在运行任务的未提交文件。最终用 Blockbench MCP 检查两任务模型，保留检查与修复证据。

- 1 个可定位、自然生成的原创陆地末地群系，完整生态闭环。
- 4 生态生物 + 4 普通怪物 + 2 精英 + 1 Boss，行为、模型、动画、存档与资源完整。
- 7 植被和 27 方块，成熟采收、种植、生长、掉落、建筑配方正确。
- 4 可定位结构，补给、精英和 Boss 仪式流程通畅。
- 中文/英文玩家文本、说明和进度记录一致；不存在占位模型、空战利品或未接入注册项。
- 编译、资源处理、相关 GameTest/服务端加载验证、模型 UV/动画审查、最终合并与远程备份均有直接证据。客户端未运行的观察项必须明确保留待测，不冒称完成。
