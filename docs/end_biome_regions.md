# 星骸与潮光统一区域调整

2026-09-30；Minecraft 1.21.1 / NeoForge 21.1.251；未新增依赖。

## 改动

旧规则先用两个独立阈值噪声选区，再让潮光优先替换中地和荒地、星骸保留高地，导致同一座岛出现青色外围包围金色岛顶。两个地表转换还各自随机跳过边界两格内的列，形成浅色末地石碎边。

当前使用一张确定性的区域地图：768 格区域网格、区域中心在格内随机偏移、坐标最大偏移 80 格，采样相邻九个中心并选择最近区域。每个区域按权重选择星骸 25%、潮光 25%、原版 50%。这只是区域选择权重，不保证每个世界的实际方块面积等于该比例。

高地、中地、荒地共用区域选择，潮光可覆盖高地，不再强制作为另一个群系的外圈。主岛及原版小岛群系不参与替换。关闭某个群系时，其区域回归原版，另一群系位置不重新分配。区域选择依赖原有世界种子绑定，不保存新的全局地图，也不增加逐 tick 工作。

删除两个地表转换中的随机边界漏涂，区域外缘使用群系地图的轻微坐标扭曲。岛底暴露的末地石、紫颂植物所需的末地石仍可能存在；本次没有将整个岛体替换成新方块。

## 连片统计
