# Boss 与精英怪战斗配置

每只已实现的 Boss、精英怪都有独立的配置文件，位于游戏或服务器的 `config` 目录。使用当前模组启动后会自动生成；开发环境对应 `run/config`。

| 生物 | 文件 |
| --- | --- |
| 裂隙螳后 | `hp_end_expansion-rift_matriarch.toml` |
| 噬星鳐王 | `hp_end_expansion-star_devourer.toml` |
| 裂隙螳螂 | `hp_end_expansion-rift_mantis.toml` |
| 裂空鳐 | `hp_end_expansion-void_ray.toml` |
| 逐星兽 | `hp_end_expansion-star_chaser.toml` |

## 属性与生效方式

`[attributes]` 中可设置 `maxHealth`、`attackDamage`、`armor`、`armorToughness`、`movementSpeed`、`followRange`、`knockbackResistance`。两种鳐额外有 `flyingSpeed`。生命和伤害的两点等于一颗心。

- 逐星兽的普通难度使用 `maxHealth`，简单与困难分别使用 `maxHealthEasy`、`maxHealthHard`。
- 螳后和鳐王各自的 `summonMinionHealth` 设置其召唤物血量；召唤物的技能仍读取各自的精英怪配置。
- 鳐王的 `starCoreHealth` 设置吞星技能生成的可击碎星核血量。
- 已有实体加载时也会应用配置，并保持修改前的血量百分比，不会因重新加载直接回满血；原有多人生命加成和阶段属性修饰符保留。
- 文件由 NeoForge 加载和监听。运行中成功重载后，会在服务端线程更新已加载实体属性。服务器的配置决定战斗数值；稳妥做法是编辑服务器文件后重启。
- 游戏原生生命属性上限为 1024、护甲上限为 30、护甲韧性上限为 20。多人加成后的最终生命仍受原生上限约束。
- `attackDamage` 控制普通攻击属性；各技能使用下面的独立伤害值。伤害仍会受到目标护甲、减伤和原版伤害处理影响。

## 共用辅助实体的伤害隔离

辅助实体不导入、读取 `CombatConfigs`。生物释放技能时读取自己的配置，再通过创建方法参数把伤害传入该次创建的飞刃、地裂、漩涡、黑洞或陨星。伤害保存在实例字段中。

- 螳后的飞刃和螳螂的飞刃分别接收各自配置，即使同一时间存在，也不会共用伤害变量。
- 鳐王的星陨和裂空鳐的星陨分别传入伤害。大陨石后续生成的星尘地面继承该次创建时传入的星尘伤害。
- 逐星兽把小陨星伤害传给自己的落点标记，标记再传给生成的小陨星。唤星者、殉星者和普通星雨使用的原有调用不受影响。
- 已生成的辅助实体使用创建时的数值；修改配置不会追溯改变它们的伤害。之后释放的技能读取新配置。

## 游戏内核对项目

1. 分别修改 Boss 血量，检查新生成与已有实体重新加载后的最大生命，已有实体应保持原血量百分比。
2. 把螳后 `stormBladeDamage` 临时改成较高值，保持螳螂 `bladeDamage = 7`，分别确认两种飞刃伤害。
3. 分别调整鳐王的大陨石、星尘与裂空鳐星陨，核对直接命中和后续伤害没有串值。
4. 调整逐星兽 `summonStarDamage`，确认唤星者、殉星者及普通星雨伤害仍保持原值。
5. 分别核对棱镜主束、分裂束及两者命中举盾目标时的伤害。
