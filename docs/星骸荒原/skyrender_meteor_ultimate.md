# 裂天之主 · 天陨（半血演出大招）

裂天之主在第二阶段掉到半血时，固定放一次大招：它撕开头顶的天幕，从裂口里拽下一颗巨大的星，压向整个坑。星落地的那一拍，场内每个玩家的生命值变成当前的一半。

大招本身不致死、躲不掉，靠演出制造压迫感，迫使玩家落地后回血。放完后裂天之主会脱力跪伏一段时间，玩家可以趁这段时间反打。

画面参考《崩坏：星穹铁道》白厄召下巨星砸地的演出：一颗燃烧的巨星从天上慢慢压下来，天地一起变暗，只剩那颗星亮着，触地时白光吞没画面，之后余烬四散。配色沿用这只首领的天幕风格：星核是深蓝黑的夜空，表面满是熔亮的裂纹，外圈是橙白色的日冕。

## 1. 触发

- **条件：** 第二阶段（`PHASE == 2`），血量不高于最大生命值的 50%，并且这场战斗还没放过天陨。
  - 用一个存进 NBT 的标记 `MeteorUsed` 记录是否放过。实体重载后，标记为真的不再放。
- **时机：** 和 `checkPhase()` 一样，在当前招式结束、回到选招时检查。不打断正在进行的招式。
- **血量地板：** 第二阶段没放过天陨时，`hurtScaled` 的地板取 `max(25% 门槛, 50% − 1)`，一刀打不穿半血线。放完后恢复为原来的 25% 门槛，第三阶段照常在 25% 进入。
- **无敌窗口：** 演出期间从开始到撞击那一拍，`invulnerableNow()` 返回真。撞击之后正常受伤。

## 2. 结算

- **结算时机：** 撞击那一拍（`METEOR_HIT`）。
- **结算对象：** 当时 `fighters()` 里每个活着、不是创造或旁观模式的玩家。
- **怎么减血：** 直接 `setHealth(getHealth() * meteorHealthRatio)`，默认比例 0.5。
  - 不走伤害系统，所以护甲、抗性、伤害吸收、附魔都不起作用，也不会触发不死图腾。
  - 只扣生命值，伤害吸收的黄心不动。
  - 当前血再低也只是减半，永远不会致死。
- **受击反馈：** 给每个被结算的玩家播一次受击动画（`ClientboundHurtAnimationPacket`）和受击音效，让玩家看得出自己挨了这一下。
- **推开：** 撞击时把所有在场玩家从坑中心往外推开（水平 1.0，竖直 0.4），不造成伤害。
- **新增配置项：** 按现有 `stat()` 的写法加到 `CombatConfigs`：
  - `meteorTrigger`：默认 0.5，触发血线。
  - `meteorHealthRatio`：默认 0.5，减血比例。
  - `meteorExhaustTicks`：默认 60，撞击后脱力的时长。

## 3. 时间线（共 200 拍 = 10 秒）

新增状态：`METEOR = 12`。时长常量：`METEOR_LEN = 200`、`METEOR_TEAR = 30`、`METEOR_DROP = 60`、`METEOR_HIT = 150`。

演出全程不选招，各招冷却暂停。星的落点固定在坑中心 `getAnchor()`，不看裂天之主站在哪，这样整个竞技场都在星的下面。

## 4. 画面实现

照参考视频（金色光环 → 云的漏斗旋涡里一颗熔岩太阳 → 太阳炸开、火环、陨石雨 → 白闪碎岩扑面 → 贴地激波、火墙、蘑菇云 → 再闪 → 熔岩缝、悬石、暗红余烬）重做，换成原版方块的样子：

- 渲染：`client/SkyMeteorRenderer`（坑底的 `SkyMeteorEntity`），屏幕和视野：`client/SkyMeteorClient`。陨石雨参数、熔岩缝格子和原版粒子在 `SkyMeteorEntity` 里，渲染和粒子用同一套伪随机，落点对得上。
- 星、陨石、碎岩、悬石用原版方块图集里的 `lava_still`、`magma`、`blackstone`，火环和落地火苗用 `fire_0`，跟着原版动画一起动。实心一层（带原版顶亮底暗的面明暗）+ 发光一层。
- 远处拉近：天旋涡在三百多格外，所有顶点离镜头超过雾起点的 0.48 倍后沿视线平滑压到雾起点的 0.8 倍以内，屏幕上不变、遮挡顺序不变，低视距也不会被雾吃掉。
- 新贴图（脚本 `art/skyrender_meteor_fx.py` 手绘生成）：`sky_vortex_cloud`（16×16 云块）、`sky_blast_wall`（64×32 火墙火舌，分三档）、`sky_blast_smoke`（32×32 蘑菇云烟团）、`meteor_flash_rocks`（64×64 四块碎岩剪影）、`sky_air_sheath`（激波罩气流纹）。沿用 `sky_star_corona`、`sky_star_flare`、`heat_ring`、`meteor_tail`、`meteor_vignette`、`sky_impact_shadow`、`sky_impact_cracks`。

## 5. 动画

新增 `animation.skyrender.meteor`，一段 10.0 秒连续播完，中途不切换动画（GeckoLib 不方便从中途起播）。

| 时间（秒） | 动作 |
|---|---|
| 0–1.5 | 后撤半步，转为人立，头仰起 |
| 1.5–3.0 | 左右前爪轮流向上撕扯，各一下 |
| 3.0–7.4 | 两爪高举保持不动，后腿逐渐下蹲，身体前倾，像扛着重量往下拽 |
| 7.4 | 双爪同时拍地。比服务端命中拍早 2 拍，和其他招式的约定一致 |
| 7.4–10.0 | 跪伏喘气，最后 0.5 秒起身回到待机姿势 |

眼睑开合继续由 `lidOpen()` 控制：演出期间全开，脱力期半闭。

人立、下蹲和跪伏都要逐帧（每 0.05 秒）检查整个模型的最低点，确认不穿地。过渡处补中间帧。

## 6. 边界情况

- **坑外玩家：** 不在 `fighters()` 里的玩家不受影响。
- **演出中下线：** 不受影响。
- **演出中进场：** 只要撞击时在 `fighters()` 里就会被结算。
- **演出中被打断：** 不可能。裂天之主在撞击前无敌，所以不会死在演出中途。
- **重载：** 如果在撞击前重载，`MeteorUsed` 还是假，血量也还在半血以下，回到选招时会重新放一次完整的演出。
- **半血线和 25% 线：** 有半血地板，玩家不可能一次打穿半血、直接跳到第三阶段。
- **多人：** 每个玩家按自己的当前血量减半。
