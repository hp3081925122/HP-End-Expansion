# 逐星兽 设计文档

状态：模型（含彗尾）、贴图、发光层、第 6.3 节全部动画已完成并接入；第 4 节的战斗状态机（出场、咬合、彗星冲锋、甩尾、嚎叫、召星、过载、脱战飞走）、难度血量、过载贴图、攻击特效（StarChaserVfx、召星落点圈 StarMarkEntity）、星雨召唤、星核余烬物品与掉落表已完成，尚未进游戏调手感。星核余烬用来合成星核胸甲（数值同下界合金胸甲，受击时 25% 几率向攻击者反溅余烬）。本文取代 [starwreck_biome_design.md](../starwreck_biome_design.md) 第 9.5 节的旧设定，旧设定不再作数。

## 1. 定位

逐星兽是星骸荒原的精英怪，也是星雨事件的收尾。每场星雨的陨星里都封着一只。它追着坠落的星穿越虚空，吃掉星核，再躲进下一颗星里睡觉。陨星砸穿地面后，它挣开外壳出来，把离得最近的玩家当成打扰它进食的东西。

它不是野外随便刷新的小怪。一场星雨最多出两只，打起来要像一场小型首领战：有预警明确的大招，血量越低越凶，打赢了掉值得的东西。

| 项目 | 设定 |
|---|---|
| 类型 | 敌对，精英（不显示首领血条，不算 Boss，不挡末影龙音乐） |
| 出现方式 | 星雨陨星落地时从陨星里出来；也能用刷怪蛋和召唤物品（第 7 节）召出 |
| 自然生成 | 无 |
| 一次最多 | 星雨的大陨星落地时各有 10% 概率出一只，每场星雨最多 2 只 |

## 2. 外形

整体印象：一头瘦长的、像豺又像彗星的猎兽。身体是被烧透又冷却的陨石，胸腔里嵌着一颗还在燃烧的星核，跑起来背后拖一条彗尾。

- 体型：肩高约 1.4 格，头到臀约 2 格，尾巴另算。四足，前腿比后腿长，站立时前高后低，像随时要扑出去。
- 身体：肋骨状的星骸岩板一片片包住躯干，板缝之间透出胸腔里的星核光。最亮的是胸口正中那颗核，从正面和侧面都能看到。
- 头：窄长的头，没有明显的嘴唇，下颌是一整块能张得很开的岩颌。眼睛是两道细长的亮缝，不是圆点。头顶向后长出一圈碎晶，像被风吹向后的鬃。
- 彗尾：尾巴本身短而粗，尾根往后拖一道由发光面片组成的彗尾，长约 2 格。跑得越快拖得越长、越直；站着不动时彗尾缩短、下垂，末端像余烬一样一明一暗。
- 爪：四只脚都是岩质的粗爪，脚掌边缘一圈余烬亮线，走过的地方偶尔留一点火星。
- 精英辨识：体型比群系里其他生物大一截，胸核和彗尾在夜里 30 格外也看得见。除此之外不要加皇冠、光环这类通用的精英标记。

### 2.1 色板

沿用星骸荒原色板，不引入新色系。

| 用途 | 颜色 |
|---|---|
| 岩板暗部 | `#1A1216`、`#2B1E1E` |
| 岩板亮部 | `#3D2B26`、`#52392D`，受光边缘可到 `#6A4A38` |
| 板缝、脚掌亮线 | `#B0581C`、`#E08C2A` |
| 星核、眼缝、彗尾芯 | `#FFCB5E`、`#FFF1C2` |
| 过载阶段（第 4.3 节）的核 | 在上面基础上整体更白，芯接近 `#FFFFFF` |

不要用裂隙螳螂那套紫色，也不要用岩浆的正红。

## 4. 行为

### 4.1 出场

1. 陨星落地的那一拍（`FallingStarEntity.impact`）不生成逐星兽，改在落点中心留一块"破壳中的陨星"。这块陨星可以是逐星兽自己在"蜷缩"姿态下的模型，也可以是独立实体，由实现的人决定。
2. 落地后 1.5 秒陨星外壳炸开：撒碎石粒子，播出场动画（第 6 节 `emerge`），不显示首领血条。
3. 出场动画期间无敌、不攻击，大约 2 秒。结束后锁定 32 格内最近的非创造、非旁观玩家。
4. 落点半径 4 格内的冲击伤害照旧由陨星结算，逐星兽本身不再额外造成出场伤害。

### 4.2 常规阶段（生命 > 50%）

| 招式 | 触发 | 表现 | 效果 | 冷却 |
|---|---|---|---|---|
| 扑咬 | 目标在 2.5 格内 | 前身压低、下颌张开，一扑合嘴 | 伤害 8 | 1.2 秒 |
| 彗尾冲锋 | 目标在 6～16 格内且有直线通路 | 原地刨地 0.8 秒，彗尾竖直拉长、变亮，脚下出现一条指向目标的地面亮线 | 沿亮线直线冲 12 格，撞到的实体受 10 伤害并被击飞；冲过的路径留 3 秒余烬地面（复用现有 `ember_ground`） | 8 秒 |
| 甩尾 | 有实体在身后 2 格内超过 1 秒 | 原地半转身，彗尾横扫 | 伤害 5，击退 | 4 秒 |
| 践踏震荡波 | 目标在 4.5 格内、高度差小于 2.5 格；贴身时约 1/3 几率代替扑咬，扑咬冷却时也会出 | 人立并追踪目标，爪下亮一圈落点提示；0.6 秒双前爪砸地，裂出亮缝，随后一圈火墙往外推 | 爪前 1.5 格处半径 2.4 格内伤害 11 并掀起；震荡波 0.5 秒内从 1.5 格扩到 7 格（过载 8.5 格），前沿扫过贴地的实体伤害 6、向外击退，跳起可躲，被爪下砸中的不再吃震荡波 | 5 秒 |

冲锋撞墙会停下并硬直 1 秒，这是玩家输出的窗口。

### 4.3 召星阶段（生命 ≤ 50%）

血量第一次降到 50% 时，它仰头长嚎一次（2 秒，期间无敌），天空的星雨特效重新亮起。之后新增：

| 招式 | 触发 | 表现 | 效果 | 冷却 |
|---|---|---|---|---|
| 召星 | 战斗中随机 | 仰头 1 秒，胸核一闪 | 在目标周围 8 格内随机 3 个点地面出现警示圈（半径 2 格），1.5 秒后各落一颗小陨星 | 12 秒 |

小陨星：外观复用星雨陨星，缩到约一半大小，从正上方约 20 格快速落下，不经过裂隙。冲击半径 2、伤害 6，不破坏方块，不伤害逐星兽自己。

### 4.4 过载阶段（生命 ≤ 25%）

岩板缝隙张开，胸核外露、颜色变白（换一张贴图或改发光层），彗尾一直拉满。

- 移速 +25%，所有招式冷却减半。
- 受到的伤害 +25%。玩家能看出"它更凶，但也更脆"。
- 不再触发新的阶段效果，打到死为止。

### 4.5 脱战与消失

- 32 格内没有可攻击的玩家超过 60 秒：它原地蜷缩，化成一颗陨星向上飞走（倒放出场），不掉落任何东西。
- 由星雨生成的逐星兽不会自然消失，但会按上一条脱战。刷怪蛋生成的按普通敌对生物处理。
- 不主动攻击其他生物，只有被打时才还手。

### 4.6 难度差异

| 难度 | 调整 |
|---|---|
| 简单 | 生命 140，不进入过载阶段 |
| 普通 | 按本文数值 |
| 困难 | 生命 220，召星落 5 颗 |

## 6. 模型与动画要求

### 6.1 资源

| 资源 | 路径 | 要求 |
|---|---|---|
| 模型 | `geo/star_chaser.geo.json` | GeckoLib，模型编号 `geometry.star_chaser` |
| 贴图 | `textures/entity/star_chaser.png` | 128×128 起，像素对齐，一格对应一像素，和群系方块同密度 |
| 发光层 | `textures/entity/star_chaser_glowmask.png` | 只包含板缝、眼缝、胸核、脚掌亮线、彗尾 |
| 过载贴图 | `textures/entity/star_chaser_overload.png` 和对应 `_glowmask` | 胸核外露、板缝更宽更亮 |
| 动画 | `animations/star_chaser.animation.json` | 见下表 |
| 碰撞箱 | 宽 1.2，高 1.4 | |

贴图手绘，按岩板分块上色，不要用程序噪声铺底。

彗尾做在模型里：尾根岩块后接三节骨骼，每节是十字交叉的两片零厚度火焰面（竖片上沿是往后扫的火舌，横片左右对称），第一节再加一根短发光芯，全部写进发光层。整条尾长约 1.6 格，按长度统一取色，根部白金、往后转橙转暗红，最后两成断成余烬。静止时三节逐级下垂 18° / 14° / 10°，跑动、冲锋时动画把它抬平拉直，蓄力时竖起，死亡时后两节缩小熄灭，尾根散出火星。面片正反两面都保留，因为发光层会剔除背面。

`client/StarChaserCoreGlow.java` 在胸核前画一片随 idle 呼吸明暗的朝镜头光晕。

### 6.2 骨骼（实际）

`root` → `body` → `chest` → `core`；`body` → `mane`、`neck` → `head` → `jaw`；四条腿 `leg_front_left` / `leg_front_right` / `leg_back_left` / `leg_back_right`，各自带 `_lower` → `_paw`；`body` → `tail` → `comet_1` → `comet_2` → `comet_3`。

`core` 是单独的骨骼，死亡动画靠缩放它分三次熄灭。

### 6.3 动画

| 名字 | 循环 | 长度 | 要点 |
|---|---|---|---|
| `emerge` | 否，停末帧 | 2.0 秒 | 从蜷缩的球形展开：先伸前腿撑地，再抬头，最后彗尾甩开 |
| `idle` | 是 | 约 3 秒 | 呼吸时胸核一明一暗，彗尾末端缓慢摆动 |
| `walk` | 是 | | 对角步态 |
| `run` | 是 | | 贴地奔跑，彗尾拉直 |
| `bite` | 否 | 0.6 秒 | 合嘴在 0.3 秒（第 6 tick），服务端在这一拍结算伤害 |
| `charge_windup` | 否，停末帧 | 0.8 秒 | 刨地，彗尾竖直 |
| `charge` | 是 | | 冲锋姿态，头压低 |
| `tail_sweep` | 否 | 0.8 秒 | 横扫在 0.4 秒命中 |
| `stomp` | 否 | 1.1 秒 | 人立 0.35～0.45 秒，砸地在 0.6 秒（服务端第 14 tick），由 `star_chaser_stomp_anim.py` 生成 |
| `howl` | 否 | 2.0 秒 | 进入召星阶段时播 |
| `summon` | 否 | 1.0 秒 | 召星时仰头 |
| `stagger` | 否 | 1.0 秒 | 冲锋撞墙后的硬直 |
| `death` | 否，停末帧 | 1.5 秒 | 倒下后胸核分三次熄灭，彗尾散成火星 |

动画的命中时刻就是伤害结算时刻，服务端按上表的 tick 结算，不要让伤害先于动作。

## 7. 召唤物品：坠星兆石

- 在星骸荒原露天处右键使用，消耗 1 个，30 秒后在附近按星雨规则落一场星雨，这场一定带逐星兽。
- 不在星骸荒原、头上没有天空、或同维度已有一场星雨时，使用无效，并提示原因。
- 贴图已有，物品还没注册。
- 合成方式待定，建议：星核余烬 ×1 + 星晶碎片 ×4 + 余烬 ×4。第一只逐星兽只能等自然星雨。

## 9. 验收

- 星雨落地后逐星兽从陨星里出来，出场期间不能被打、不会攻击。
- 三个阶段按 50% 和 25% 生命切换，每个阶段的新招式都在玩家面前出现过至少一次。
- 冲锋有 0.8 秒可见预警，撞墙会硬直；召星的警示圈出现 1.5 秒后才落陨星。
- 逐星兽被自己的冲锋余烬和小陨星打到不掉血。
- 离开 32 格超过 60 秒，它飞走且不掉落。
- 杀死后必掉星核余烬。
- 困难难度下召星落 5 颗，简单难度下不进入过载阶段。
