# 负星者 设计文档

ID：`star_bearer`。星骸荒原的精英敌怪，属于坠星教团（见 [群系设计](../starwreck_biome_design.md) 9.6、9.7 节）。

状态（2026-10-01）：模型、贴图、发光层、11 个动画、实体、生成和掉落已接入。还没进游戏验收。

## 1. 定位

教团把星雨当启示，被陨星砸中是「受选」。唤星者是祭司，殉星者是狂信徒，负星者是教团的朝圣者：他把一颗还在燃烧的坠星装进圣龛，背着它在荒原上走。

- 玩法：一场走位战。负星者走得慢、正面很硬；背后那颗坠星是弱点。玩家要绕到背后打星，同时躲开砸地冲击环和背后的星焰。
- 两种形态：背星形态（圣星完好）和碎星形态（圣星被打碎后狂暴）。
- 和逐星兽的区别：逐星兽是快、要躲的冲锋怪；负星者是慢、要绕的坦克怪。两者不要同时出现（见第 5 节）。

## 2. 外形

总高约 3.2 格（含背上圣龛），本体到兜帽顶约 2.3 格。身体前倾，像被背上的重量压弯。

| 部位 | 外形 |
|---|---|
| 腿 | 粗短，膝盖有护板，脚上一双大号岩靴 |
| 腰 | 夜空色布腰带，两道金箍，正中一块金扣 |
| 前后布裙 | 夜空色长条布从腰带垂到小腿，金色滚边，下摆破碎；前片绣一道金色坠星纹 |
| 躯干 | 夜空色长袍外罩一整块星骸岩胸甲，胸甲上沿镀金；胸口嵌一枚菱形星晶，上方三道金色斜纹，组成坠星纹 |
| 肩 | 两块外翻的厚岩肩甲，下面一片短甲 |
| 手臂 | 上臂缠布，前臂岩质护腕，拳头是两只超大的岩拳套，指节一排发光余烬缝。双拳垂到膝盖，砸地用 |
| 头 | 头偏小，压在两肩之间。夜空色兜帽，前沿一圈金边；脸上一块无面的灰白石面具，正中一道竖直的发光细缝 |
| 圣龛 | 背板挂在后背上，向后伸出一块平台，四根黑岩柱撑起一个镀金檐的小屋顶，屋脊立一枚星晶尖。柱间两层金箍，像一只笼子 |
| 圣星 | 笼里托座上一颗约 0.6 格的焦黑陨石，布满发光裂缝，表面伸出三根星晶。火焰和火星用粒子做，不建模 |
| 碎星 | 圣星打碎后只剩托座上的一堆焦黑残块和一根断晶，裂缝光变暗 |

色板：岩、晶沿用群系第 2 节；布和金沿用唤星者、殉星者的夜空色和金色。

## 3. 行为

### 3.1 常态

- 敌对。发现距离 24 格，追踪时一直朝目标走，不会主动后退。
- 出招期间锁定朝向。光束会带着身体跟着光束方向转。
- 走路：移速很慢，脚步沉重，每步有低沉的落地声。
- 不会游泳上浮，不会被推动。

### 3.2 正面、侧面、背面

按攻击者（或弹射物）相对负星者身体朝向的水平夹角判定：

| 方向 | 夹角 | 效果 |
|---|---|---|
| 正面 | 0～60° | 受到的伤害乘 0.3；弹射物直接弹开，不受伤 |
| 侧面 | 60～120° | 正常受伤 |
| 背面 | 120～180° | 正常受伤，同时圣星受到同样的伤害 |

弹射物从背面射来时，还要命中点高度 ≥ 1.6 格才算打在圣星上，低于这个高度按侧面处理。近战只看夹角。狂暴后正面减伤失效。

### 3.3 招式

| 招式 | 条件 | 过程 | 效果 | 冷却 |
|---|---|---|---|---|
| 圣砸 | 目标在 4 格内、在正前方 ±45° | 双拳举过头顶 1.0 s（锁朝向），然后砸地 | 前方 3 格、90° 扇形内 10 点伤害并强击退；同时从落点放出一圈贴地冲击环，0.6 s 内从 1 格扩到 6 格，环扫过时站在地面上的实体受 6 点伤害并被上挑。跳起来可以躲过冲击环 | 3 s |
| 星焰反扑 | 只在背星形态。目标在背面持续 1.5 s，或 3 s 内圣星被打 2 次 | 弓背低头，圣星亮起 0.6 s 预警，然后向背后喷焰 | 背后 4 格、60° 锥形内 6 点火焰伤害、击退，点燃实体 2 s，不点燃方块 | 6 s |
| 圣星抛射 | 只在背星形态。目标在 8～24 格、视线可达 | 后仰伸手到肩后 0.8 s，掰下一块星，甩出 | 一次甩出 5 块（目标在移动时脚下再多 1 块）：一块落在预判点，四块围在 2.6 格外。每块半径 2 格、6 点伤害，1.5 s 后落地，落点各有小圣印 | 8 s |
| 连砸 | 只在碎星形态。替代圣砸 | 连砸两下，每下前摇 0.6 s（`slam_fast` 连播两遍） | 每下都等同圣砸 | 2 s |
| 负星横扫 | 目标在 4.5 格内、在侧面 40°～110°，或在正前方时 35% 概率代替圣砸 | 拧腰把右拳抡到右后方，拳上聚冷光 0.6 s，然后 0.2 s 横抡到左前方 | 弧光前锋 4 tick 从右后 -130° 扫到左前 60°、半径 4.2 格，扫到谁打谁：9 点伤害，顺挥砍方向横甩出去。右侧比左侧早挨 2 tick | 3.5 s |
| 负星光束 | 目标在 7～22 格、视线可达、在正前方 ±25°；碎星形态也会放 | 双臂后张挺胸，胸口星晶蓄力 1.0 s（有一根细瞄准线，朝向每 tick 追 2.5°），然后开火照射 1.2 s | 光束长 24 格、会被方块挡住，每 0.5 s 一跳 5 点伤害。开火后瞄准每 tick 只能挪 0.9°（狂暴 1.5°），横向跑就能甩开，站着不动会被一直照 | 11 s（狂暴 8 s） |

- 特效不复用星雨那套橙红余烬，负星者单独走「白金圣火」路线，画面全部由 `BearerVfxEntity`（只画不结算、不存档）和 `StarShardEntity` 负责，贴图在 `textures/effect/bearer_*.png`，生成脚本 `D:\AI临时文件\starfall_vfx\build_bearer_vfx.py`：
  - 圣砸：地面烙下旋转圣印、八道地裂光纹、中心光柱，一圈竖直光墙沿伤害环推出，墙脚掀起地表方块碎块。光墙半径和伤害判定共用 `BearerVfxEntity.ringRadius`；伤害只打 `onGround()` 的实体。
  - 星焰：从圣星向背后喷出三片白金火舌面，内芯更白，纹理沿喷射方向滚动；前摇期间圣星的圣辉越聚越亮（渲染器读 `chargeUp`）。
  - 碎星：白闪、十二道放射光刺、一横一斜两圈光环，金色碎晶四溅、落地会弹。
  - 抛星：碎星本体是金色圣辉加旋转十字光芒、拖白金火舌；落点圣印随蓄势加速旋转，临落地时垂下一线光；落地放一个小号圣砸。
  - 常驻：圣星外一团呼吸的圣辉，冒白金圣焰粒子 `bearer_flame`；碎星后改成暗红余光；狂暴后甲缝喷赤焰 `bearer_rage`。
- 横扫和光束走另一条「负光」路线：靛紫到青白的冷色，粒子是吸光的虚蚀微粒 `bearer_void` 和青白星芒 `bearer_glint`，贴图生成脚本 `D:\AI临时文件\starfall_vfx\build_bearer_vfx2.py`：
  - 横扫：前摇时虚蚀微粒被吸进右拳，拳上一颗四芒星越聚越亮、外面一道光环往里收；出手时一片右高左低的斜劈弧光（靛紫拖尾、青白刃口、外沿一圈弧形光幕），晚 1.5 拍跟一道暗些的回响弧，前锋挂一颗旋转四芒星。弧光角度和伤害共用 `BearerVfxEntity.arcLead`。
  - 光束：蓄力时微粒吸进胸口，两道光环沿光束方向向内收拢，一根闪烁的细瞄准线；开火时双层光束（外层绞索纹理沿光束往外滚、内层青白芯），光环每 2 格一道顺光束外流，两端各一颗四芒星，落点炸虚蚀微粒和方块碎屑。光束长度客户端每 tick 按方块碰撞重算，和服务端判定一致。
- 碎星和所有范围伤害都不伤坠星教团同伴（负星者、殉星者、唤星者），也不伤负星者自己。

### 3.4 碎星与狂暴

- 圣星生命 30，只吃背面伤害（见 3.2）。
- 圣星生命归零时碎星：
  1. 圣星炸开：以圣星为中心半径 3 格内 5 点伤害（会打到贴在背后的玩家），伴随 `star_debris` 大量飞溅。
  2. 硬直 4 s：负星者跪地，不移动、不出招，受到的伤害乘 1.5。这是主要输出窗口。
  3. 起身怒吼 1.2 s，进入狂暴。
- 狂暴（碎星形态）：
  - 移速乘 1.4。
  - 正面减伤失效，所有伤害乘 1.25。
  - 圣砸换成连砸，星焰反扑和圣星抛射不再出现。
  - 板甲缝里持续喷 `star_ember` 火星。
- 碎星不可逆，脱战也不会复原。

### 3.5 脱战

32 格内没有目标超过 60 s，回满生命；圣星状态不变。

## 7. 动画

动画文件 `animations/star_bearer.animation.json`，前缀 `animation.star_bearer.`。时间以秒计，命中时刻同时给出 tick 数，代码按 tick 结算伤害。

| 名字 | 长度 | 循环 | 内容 |
|---|---|---|---|
| `idle` | 3.0 | 是 | 沉重呼吸，胸口起伏；圣龛随呼吸轻晃，双拳微摆 |
| `walk` | 1.6 | 是 | 重步，每步落地身体下沉 1 像素；圣龛滞后一拍晃动；拳头前后小摆 |
| `walk_rage` | 1.1 | 是 | 狂暴走路，前倾更大、步子更急 |
| `slam` | 1.6 | 否 | 0～1.0 双拳举过头顶、上身后仰；1.0（第 20 tick）砸到身前地面；1.0～1.6 收回 |
| `slam_fast` | 1.0 | 否 | 狂暴连砸的一下，0.6（第 12 tick）命中；连砸 = 连播两遍，两次命中分别在第 12、32 tick |
| `backfire` | 1.2 | 否 | 0～0.6 弓背低头，圣龛前倾露出；0.6（第 12 tick）喷焰；之后起身 |
| `toss` | 1.4 | 否 | 0～0.8 右手伸到肩后；0.8（第 16 tick）甩出；之后收回 |
| `sweep` | 1.3 | 否 | 0～0.6 拧腰、右拳抡到右后方；0.6～0.8（第 12～16 tick）横抡到左前方；之后收回 |
| `beam` | 2.7 | 否 | 0～0.35 双臂后张挺胸；0.35～1.0 蓄力微颤；1.0（第 20 tick）开火、被反冲推后；1.0～2.2 照射（第 44 tick 停火）；2.2～2.7 收回 |
| `shatter` | 0.8 | 否 | 碎星瞬间被冲击得向前踉跄，接 `stagger` |
| `stagger` | 1.0 | 是 | 单膝跪地，双拳撑地喘息 |
| `rage` | 1.2 | 否 | 起身，双拳捶地，仰头 |
| `death` | 2.0 | 停在末帧 | 跪下再向前扑倒；圣星完好时，`star` 骨骼最后向后滚落半格 |

### 8.2 骨骼

```
root
└ body                 腰，轴心在髋
  ├ skirt_front        前布裙，轴心在腰带下沿
  ├ skirt_back         后布裙
  ├ leg_left → shin_left     大腿 → 小腿+靴，shin 轴心在膝
  ├ leg_right → shin_right
  └ chest              上身，静止姿态前倾 14°
    ├ head             静止姿态回抬，补偿上身前倾
    ├ arm_left → forearm_left    肩甲+上臂 → 护腕+拳套
    ├ arm_right → forearm_right
    └ shrine           圣龛（背板、平台、柱、笼箍、屋顶）
      ├ star           圣星（完好）
      └ star_broken    碎星残块
```

- `star` 和 `star_broken` 在模型里同时存在、位置重叠。渲染器按同步的碎星状态隐藏其中一个：完好时隐藏 `star_broken`，碎星后隐藏 `star`。
- 圣星燃烧的火焰：渲染器每 tick 取 `star` 骨骼的世界坐标，往上冒 `star_ember`，偶尔冒 `star_ash`。碎星后改从 `star_broken` 冒，频率降到四分之一。
- 死亡时不要叠加原版的侧翻，否则 `death` 动画会被遮住（和逐星兽、余烬甲虫同样处理）。

### 8.3 发光区域

胸口星晶、面具竖缝、拳套指节缝、圣星裂缝和三根星晶、屋脊晶尖、碎星残块里的余烬缝。

## 9. 代码接入

- 新增 `StarBearerEntity`，写法照 `StarMartyrEntity`：GeckoLib 动画控制器、服务端用同步数据驱动招式动画。
- 同步数据：`STAR_BROKEN`（布尔）、`STAR_HEALTH`（浮点，给渲染器做圣星受击闪白用，可选）、当前招式编号。
- 方向判定写在 `hurt` 覆写里：用 `source.getSourcePosition()`（没有就用攻击者位置）算夹角。
- 冲击环：服务端在 0.6 s 内逐 tick 扩半径，记录已命中的实体，同一环同一实体只打一次。
- 注册：实体类型、属性、刷怪蛋、渲染器、中英文名字（中文"负星者"，英文 "Star Bearer"）、生成表、掉落表。
