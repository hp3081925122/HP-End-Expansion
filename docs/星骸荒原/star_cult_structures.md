# 拜星教派结构设计

拜星教派结构只生成在星骸荒原，建筑材料统一使用星骸砖、余烬星骸石和星晶，轮廓保持低矮、厚重、带有向天空指向的祭柱。三种结构共享一个结构集，按 5:3:1 的权重出现，结构间距为 42 区块，最小分离距离为 20 区块。

## 星盏观测台

- 尺寸：15×15，半径 7，高度 10。
- 定位：小型路标和教徒观星点。
- 形制：圆形星骸砖基座、四角矮柱、中心星晶柱、十字形余烬星纹，以及一个小型储物箱。
- 生成权重：5。
- 宝箱：末晶尘、星晶碎片和紫水晶碎片，作为低风险探索奖励。

## 星骸祷室

- 尺寸：21×17，半径 10，高度 11。
- 定位：中小型教派聚会场所。
- 形制：带四角高柱的长方形祷室，内部有成排座位、前方星晶圣坛和地面十字星纹，屋顶保留末地烛光通道。
- 生成权重：3。
- 宝箱：星陨兆、星核余烬、星晶碎片和末影珍珠。

## 裂穹祭坛

- 尺寸：25×25，半径 12，高度 14。
- 定位：稀有的中型仪式场，用来表现拜星教派对天穹裂隙的崇拜。
- 形制：三级圆台、中央高耸星晶柱、八根环形祭柱、余烬放射线和悬空星环，祭坛入口放置高价值储物箱。
- 生成权重：1。
- 宝箱：星引信标、天幕碎片、星晶碎片和末影之眼。

结构通过自定义 `StarCultStructure` 和 `StarCultPiece` 直接生成，不依赖外部结构编辑器或额外模组。地形检查会拒绝高度差过大的位置，减少建筑悬空或嵌入岛屿边缘的情况。
